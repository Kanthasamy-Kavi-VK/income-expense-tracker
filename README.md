# Income Expense Tracker

A web application for managing and tracking income and expenses.

## Features

* Track income
* Track expenses
* View financial information
* Manage transactions

## Tech Stack

* React
* Vite
* JavaScript
* CSS

## Getting Started

Install the project dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the URL shown in the terminal.
